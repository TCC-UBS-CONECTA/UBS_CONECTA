# UBS CONECTA

Sistema web desenvolvido com o objetivo de auxiliar na organização e otimização dos processos realizados em Unidades Básicas de Saúde (UBS).

O UBS CONECTA busca centralizar informações, facilitar o acesso aos serviços de saúde e contribuir para a organização do atendimento de pacientes e profissionais.

---

## Sobre o projeto

O UBS CONECTA é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), tendo como proposta o desenvolvimento de uma solução tecnológica voltada às Unidades Básicas de Saúde.

O sistema está sendo desenvolvido de forma gradual, passando pelas etapas de planejamento, desenvolvimento da interface, modelagem do banco de dados, implementação do back-end e integração entre as diferentes tecnologias utilizadas.

---

## Objetivo

Desenvolver uma plataforma tecnológica capaz de auxiliar na organização das informações e na otimização dos processos de atendimento em Unidades Básicas de Saúde.

### Principais funcionalidades planejadas

- Cadastro de usuários
- Login e autenticação
- Área do paciente
- Área do profissional
- Localização e informações das UBS
- Agendamento de consultas
- Gerenciamento de consultas
- Gerenciamento de perfil
- Armazenamento e organização das informações
